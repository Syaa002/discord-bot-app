📖 Panduan Fungsi 18 Tombol Kontrol

🛠️ Pengaturan Ruangan

  • 👥 LIMIT — Menentukan jumlah maksimal member di room.
  • 💬 CHAT — Membuka akses obrolan teks saluran.
  • 🏷️ NAME — Mengganti nama voice room sesuka hati.
  • 🔒 PRIVACY — Mengunci room agar orang asing tidak masuk.
  • 📶 BITRATE — Menyesuaikan kualitas suara panggilan.
  • 🌐 REGION — Memilih lokasi server Discord terdekat.
  • ⚙️ RESET — Mengembalikan setelan voice ke default.

🛡️ Izin & Keamanan

  • 📞 KICK — Mengeluarkan user yang mengganggu.
  • 👤 TRUST — Memberikan izin bicara dan bypass kunci.
  • 👤 UNTRUST — Menghapus status trusted pengguna.
  • 🚫 BLOCK — Memblokir user agar tidak bisa join.
  • 🔓 UNBLOCK — Membuka blokir pengguna tertentu.
  • ⏳ WAITING ROOM — Member harus diizinkan sebelum berbicara.
  • 📞 INVITE — Membuat link undangan cepat ke ruangan.

👑 Kepemilikan & Status

  • 👑 CLAIM — Klaim otomatis jika pembuat room telah keluar.
  • 🔄 TRANSFER — Menyerahkan hak milik room ke teman.
  • 🗑️ DELETE — Hanya Pemilik / Admin yang bisa menghapus.
  • ℹ️ INFO — Menampilkan data statistik room secara ephemeral.
